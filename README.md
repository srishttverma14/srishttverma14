## 👋 About Me

Hi, I'm **Srishti Verma**! I enjoy creating practical web applications and experimenting with projects across **AI/ML, frontend development, and interactive tools**. I like taking an idea from a simple prototype to something people can use.

- 💻 I build web projects with **JavaScript, React, Next.js, and TypeScript**.
- 🤖 I explore AI-powered applications and machine-learning workflows.
- 🧠 I've worked on projects ranging from **handwritten digit prediction** to **AI-assisted interview practice**.
- 🎨 I enjoy building user-friendly tools, including a customizable signature generator.
- 🌱 Always learning, improving, and adding new projects to my portfolio.
